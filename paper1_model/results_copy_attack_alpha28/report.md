# 复制攻击与内容绑定实验

## 实验配置

- 正样本水印供体：50 张
- 负样本复制目标：50 张
- 内容绑定阈值：0.3
- 载体/编码：dwt_dct / rs_repeat / repeat=4 / alpha=28.0

## 结论

- 内容绑定关闭时，复制攻击会被数据库联合验证接受，说明仅靠 CRC/RS/generation_id 不足以证明水印属于当前图像。
- 内容绑定开启后，复制攻击应被拒绝，同时正样本在常见攻击下保持可用。
