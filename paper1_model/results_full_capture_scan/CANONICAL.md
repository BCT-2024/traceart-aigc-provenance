# Canonical Single-Attack Result

This directory is the canonical source for the final `alpha=28` single-attack
results.

- 200 registered positives;
- 100 clean negatives;
- 15 single-attack rows per positive;
- 3,000 positive attack records;
- 200 registered images under each of the two physical stress simulators.

The directory contains the complete quality, robustness, negative, and summary
artifacts used by Table 4 and Figs. 5, 6, 8, and 9. The earlier partial result
directory is retained for provenance only.
