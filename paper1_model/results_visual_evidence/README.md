# Visual Evidence

Generated by `paper1_model/generate_visual_evidence.py` with `alpha=28` and
seed 20260910.

## Multi-method comparison

`multimethod_examples.csv` contains:

- one landscape and one portrait image;
- Original, Ours, external DWT-DCT, external DWT-DCT-SVD, and RivaGAN;
- PSNR and SSIM for every watermarked image;
- payload length: 1024 coded bits for Ours and the transform baselines, 32 bits
  for RivaGAN.

The representative source in each category is selected by median PSNR rather
than visual preference. Images are stored under `multimethod/`.

## End-to-end cases

`case_gallery.csv` contains one registered portrait image under:

- clean;
- JPEG quality 70;
- center crop 0.9;
- print-scan simulation.

The source is selected from images that succeed under clean, JPEG70 and crop0.9,
using the median PSNR within that eligible set. The print-scan case is retained
as a known failure. Each row records the decoded/expected ID prefix, CRC, RS,
BER, content-binding score, alignment, trust level, and final decision.

Images are stored under `case_gallery/`.
