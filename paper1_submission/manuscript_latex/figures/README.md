# Generated Figure Files

The Paper 1 figure bundle is generated by
`paper1_model/make_paper_figures.py`.

Each figure is exported in four formats:

- SVG: editable vector working copy;
- PDF: preferred manuscript/submission vector format;
- PNG: 600 dpi preview;
- TIFF: 600 dpi raster fallback.

The manuscript figure sequence is:

1. `fig1_framework`
2. `fig2_payload_ecc`
3. `fig3_dwt_dct`
4. `fig4_verification`
5. `fig5_watermark_example`
6. `fig6_robustness`
7. `fig7_ablation`
8. `fig8_calibration`
9. `fig9_external`
10. `fig10_multimethod_visual`
11. `fig11_case_gallery`
12. `fig12_failure_attribution`

`graphical_abstract` is a separate submission asset and is not part of the
numbered figure sequence.
